📅 Conectar Google Calendar (tu cuenta personal)
Con esto, al tocar "Agregar a Calendar" el evento se crea directo en tu Google Calendar (sin abrir un link). Pasos para tu Client ID (gratis, ~5 min):
1. Ve a console.cloud.google.com → crea un proyecto
2. "APIs y servicios" → "Biblioteca" → habilita Google Calendar API
3. "Pantalla de consentimiento OAuth" → tipo Externo → agrégate como usuario de prueba
4. "Credenciales" → "Crear credenciales" → ID de cliente de OAuth → tipo Aplicación web
5. En "Orígenes de JavaScript autorizados" agrega la URL exacta de tu app (ej. https://tuusuario.github.io)
6. Copia el Client ID, pégalo arriba, guarda la configuración y toca "Conectar con Google"
Sin conectar, "Agregar a Calendar" sigue funcionando como antes (abre un link para agregarlo manualmente).
